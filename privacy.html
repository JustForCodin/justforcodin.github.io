Privacy policy

Last updated: October 16, 2026

n8n uploader is a personal tool used only by its owner to upload videos to the owner's own YouTube channel.

What data the app accesses

With the owner's permission, the app uses Google's YouTube Data API to upload videos and set their titles, descriptions and privacy settings on the owner's channel. It does not access any other Google data.

How data is stored

The sign-in token from Google is stored only on the owner's own computer, inside the n8n automation software. No data is collected from, sold to, or shared with anyone else.

Other users

The app is not offered to the public. Nobody other than the owner signs in to it, so it collects no data about other people.

Google API Services

The app's use of information received from Google APIs follows the Google API Services User Data Policy. You can remove the app's access at any time at myaccount.google.com/permissions.
